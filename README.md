# Formulário de Contato Responsivo

Formulário de contato moderno, totalmente responsivo e integrado com envio de e-mails em tempo real sem a necessidade de um servidor backend próprio.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do formulário.
* **CSS3:** Estilização personalizada, layout responsivo e efeitos visuais.
* **JavaScript:** Validação de campos, máscara de telefone em tempo real e requisição assíncrona (`fetch`).
* **Web3Forms API:** Serviço de integração para envio dos e-mails direto para a caixa de entrada.

## ✨ Funcionalidades

* 📱 Layout adaptável para telas de computadores e celulares.
* 📞 Formatação e máscara automática para número de telefone/WhatsApp `(00) 00000-0000`.
* ✉️ Validação de e-mail em tempo real.
* 🛡️ Proteção básica contra bots (Honeypot).
* ✅ Feedback visual instantâneo de envio com sucesso.
